# 测试账号与部署说明

## 1. 测试账号（复赛评委直接可用）

服务启动（`lifespan`）会**自动预置**演示账号，无需手动注册：

```
用户名：demo
密码：  demo123
```

- 用途：登录 **real 源**体验多租户隔离 + 实际数据洞察（real 源默认空库，可在「数据录入」添加案件或用 CSV 导入）。
- demo 源（默认）为共享演示库，**无需登录**即可体验全部功能，适合评委快速走查。
- 令牌：HMAC-SHA256 无状态签名，7 天有效；`AUTH_SECRET` 生产务必固化（否则重启失效）。
- 注册新账号：`POST /api/auth/register {username,password,tenant_name}`；登录：`POST /api/auth/login`。

## 2. 本地运行

```bash
cd returnguard/demo
pip install -r requirements.txt        # 或复用受管 venv
python main.py                         # http://localhost:8000
```

Docker（热更新，推荐演示）：

```bash
cd returnguard/docker
docker compose -f docker-compose.local.yml up --build
# 绑定挂载 ../demo + uvicorn --reload；改代码无需重建镜像
```

## 3. 环境变量（`.env`，不入 git）

| 变量 | 说明 | 当前 |
|------|------|------|
| `MODEL_ROUTER_API_KEY` | Token Plan 专属 Key（文本/语音已生效） | 已配置 |
| `MODEL_ROUTER_BASE_URL` | 网关基地址（**复赛期间保持不变，仍用测试网关**） | token-plan…/compatible-mode/v1 |
| `MODEL_ROUTER_TEXT_MODEL` | 默认 qwen3.7-max，可切 kimi/deepseek/flash | qwen3.7-max |
| `PUBLIC_IMAGE_BASE` | 上传图公网前缀（视觉能力开通前置） | 空（P3-17 收口） |
| `RG_OSS_*` | 对象存储图床（可选，替代 PUBLIC_IMAGE_BASE） | 未配 |
| `AUTH_SECRET` | 令牌签名密钥（生产必配） | 演示态随机 |
| `FORCE_RESEED` | =1 仅重置 demo 种子库（不动 real） | 不常设 |

## 4. 公开仓库

- **主仓库（GitHub）**：https://github.com/a703201/ReturnGuard （已推送至 `main`）
- **镜像（Gitea，树莓派 3B+）**：`git@100.103.184.33:a703201/ReturnGuard.git`
- **GitCode 镜像步骤**（满足复赛「公开可访问仓库」要求）：
  1. 注册 GitCode 账号，新建空仓库 `ReturnGuard`。
  2. 本地添加远程：`git remote add gitcode <gitcode 仓库 SSH/HTTPS>`。
  3. 推送：`git push gitcode main`。
  4. 在仓库「设置 → 可见性」设为 **Public**，勾选「允许访客查看」。
  5. 如需 CI 自动镜像，可在 `.github/workflows` 加定时 `git push --mirror gitcode`。
- 提交规范：每次改动提交并**双路推送**（origin + gitea），保留 CHANGELOG.md 与 `VERSION` 同步。
