# ReturnGuard 技术文档

## 1. 系统架构

```
┌──────────────────────────────────────────────────────────────┐
│  前端（static/index.html，纯静态 + Fetch，无框架依赖）          │
│   · 单案举证表单 / 群体洞察看板 / 数据录入 / 模型编排链路面板    │
└───────────────┬──────────────────────────┬───────────────────┘
                │  /api/analyze (POST 多部件) │  /api/insights (GET)
                ▼                            ▼
┌──────────────────────────────────────────────────────────────┐
│  FastAPI 服务 (main.py)                                        │
│   · 双源隔离：demo（共享演示库）/ real（多租户隔离，需登录）     │
│   · 图床层 storage.py：上传图 → 公网 URL（OSS / PUBLIC_IMAGE_BASE）│
│   · 账户体系 auth.py：pbkdf2 哈希 + HMAC 无状态令牌 + 租户隔离   │
└───────────────┬──────────────────────────┬───────────────────┘
                ▼                            ▼
        ┌──────────────┐            ┌──────────────────┐
        │ pipeline.py  │            │   db.py          │
        │ 阶段A 取证    │            │ SQLAlchemy 双轨   │
        │ 阶段B 聚合    │            │ SQLite(开发)      │
        │ 归因          │            │ / openGauss(部署) │
        └──────┬───────┘            └──────────────────┘
               │ 模式路由
     ┌─────────┴──────────┐
     ▼                    ▼
 mock（确定性规则）   live（models_router.py）
                     └─ 阿里云百炼 Token Plan 网关（OpenAI 兼容）
```

**模式自动路由**：demo 源默认 `mock`（演示数据，免 Key 立即可跑）；real 源默认 `live`（真实 AI）。无需前端切换（洞察模式选择器已移除，按数据源自动路由）。

## 2. 模型调用清单（逐能力 · 真实 / 回退映射）

`models_router.py` 统一封装「方案功能」对应的模型能力，经 **Token Plan 专属网关**（OpenAI 兼容协议）调用。每个能力独立可用、**逐能力回退**：单点失败仅该能力回退 mock，其余真实能力仍生效。

| 编号 | 功能 | 模型（网关命名） | 真实能力 | 回退策略 | capabilities 标记 |
|------|------|------------------|----------|----------|--------------------|
| ① | 同款一致性比对 | `qwen/tongyi-embedding-vision-plus`（图向量） | 两张图向量 → 余弦相似度 | 确定性哈希相似度 | `similarity` |
| ② | 瑕疵识别（标签） | `qwen/qwen3-vl-plus`（多模态） | 肉眼可见瑕疵标签 | 确定性哈希标签 | `defects` |
| ②' | 缺陷定位（红框） | `qwen/qwen3-vl-plus`（多模态 bbox） | 归一化 bbox 坐标框 | 确定性示意框（按标签） | `boxes` |
| ③ | Listing 承诺提取 | `qwen/qwen-vl-ocr`（OCR） | 本店承诺文字 | 回退 listing_text | `ocr` |
| ④ | 文本归因 / 卷宗 / 陈述 | `qwen3.7-max`（默认，可换 kimi/deepseek/flash） | **已真跑通** | — | 始终真实（live 下） |
| ⑤ | 案件优先级 | `qwen3-rerank`（多案重排） | 单案用确定性公式 | 本地公式 | — |
| ⑥ | 母语语音陈述 | `qwen-audio-3.0-tts-plus` | **已真跑通** | 占位 WAV | `tts` |

> **当前网关开通状态**（Token Plan 团队版）：④ 文本推理、⑥ TTS 已开通并真跑通；① 图向量、②/②' 多模态理解、③ OCR、⑤ rerank **未开通**，自动回退演示。网关开通对应模型后，红框/同款/承诺即实时变真，**无需改代码**（`MODEL_ROUTER_BASE_URL` 不变）。

## 3. 关键帧红框标注 live 化（本阶段重点）

- **真实路径**：`vl_detect_boxes()` 以 `DEFECT_BBOX_PROMPT` 要求多模态模型返回归一化 `[x,y,w,h]` + 置信度的 JSON bbox；解析后作为 `defect_boxes` 返回，`capabilities["boxes"]=True`。
- **回退路径**：网关未开通视觉理解 / 解析失败时，按已知缺陷标签生成**确定性示意框**，`capabilities["boxes"]=False`。
- **前端呈现**：`renderAnnot(boxes, imgUrl, boxLive)` —— 真实框为**红色实线**并标注「AI 实算」；回退框为**琥珀色虚线**并标注「（示意）」；并展示来源徽标，确保评委/用户不被误导为平台裁决依据。
- **契约**：`schemas.AnalyzeResult.defect_boxes_live` 显式标记红框是否来自真实视觉模型。

## 4. 数据口径与指标说明（务必如实呈现）

- **胜诉率（win_rate）**：demo 种子约 30%（与方案吻合）；为**历史纠纷结果分布参考**，**不代表选品成功率**，提示词已约束不将其当作预测。
- **争议率（avg_dispute_rate）**：为**代理指标**——由「退货图与本店主图相似度」推算，并非平台标记的争议笔数；前端显式标注「代理指标」。
- **退货成本 / 物流占比**：基于宏观地区粗略比例估算（单来源假设），用于选品层级的成本意识，非精确财务核算。
- **demo / real 双源物理隔离**：聚合缓存不串扰；demo 源从 `cases.json` 播种，real 源初始空库待录入（网页「数据录入」或 CSV 导入）。

## 5. 安全与多租户（C 组能力）

- 上传图校验 + 落盘路径穿越断言（防 `../`）；红框标签 `esc()` 转义 + CSP 头，杜绝 live 模型自由文本的 XSS（P1-3）。
- 账户：pbkdf2 加盐哈希（10 万轮）不存明文；令牌 HMAC-SHA256 无状态签名，登出自增 `token_version` 即时吊销。
- real 源案件按 `tenant_id`（=用户名）隔离；demo 源为共享演示库。

## 6. live 真跑通的激活路径（部署清单）

1. **密钥**：`MODEL_ROUTER_API_KEY`（Token Plan 专属 Key，须与专属基地址配套；`.env` 不入 git）。
2. **文本 / 语音已生效**：④⑥ 在 `live` 模式下默认真实。
3. **视觉能力开通条件**：
   - 图床：`PUBLIC_IMAGE_BASE=<公网可访问 /uploads 前缀>` 或配置 `RG_OSS_*`（对象存储），使上传图可被网关服务端回源。
   - 网关开通多模态理解（②/②'）、图向量（①）、OCR（③）后，对应红框/同款/承诺即实时变真。
4. 当前未配置公网图床（P3-17 收口）与视觉模型，故 live 模式视觉三步回退演示、文本/语音真实——演示不中断且如实标注。

## 7. 运行方式

- 本地：`cd demo && python main.py` → http://localhost:8000
- 容器（热更新）：`cd docker && docker compose -f docker-compose.local.yml up` → 绑定挂载 `../demo` + uvicorn `--reload`
- 测试：`pytest tests/` （当前 75 passed）
