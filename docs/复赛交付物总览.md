## 阶段成果说明（v1.1.1）

**定位**：退货纠纷数据驱动的「选品避坑 + 品控洞察」情报站。单案客观取证（只取证不裁决）+ 群体退货数据聚合为市场洞察。

- **A 组 · 假能力变真（live 多模态）**：真实接入图向量同款比对 / VL 瑕疵识别（真实红框）/ OCR / rerank；统一图床抽象（OSS / `PUBLIC_IMAGE_BASE` / 本地回退）；未开通模型**逐能力自动回退 mock 并标记**，gateway 渐进开通即生效。
- **B 组 · 数据闭环**：时间序列 + 次月预测预警；CSV 批量导入真实退货（`POST /api/import_csv`）；相似度阈值**自标定**（Youden J 最优切点）；选品避坑可执行清单。
- **C 组 · 多租户 + 合规 + 国产化**：注册/登录/令牌（一用户一租户），real 源按租户隔离；XSS 全转义 + CSP 防御纵深；demo/real 双源物理隔离；openGauss 部署 + 启动自动导入（`RG_AUTO_IMPORT_CSV`，幂等）。
- **安全**：公网部署语境下 SEC-1~12 全清零（写接口鉴权、签名短链收敛 PII、CSP nonce、多 worker 共享状态外置、KDF 60 万轮、Key 常量时间比较）。测试由 65 → 85。
