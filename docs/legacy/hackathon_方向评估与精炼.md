# AI+跨境黑客松 · 方向评估与精炼

> 评估口径：业务价值(BV) / 创新性(INN) / 可行性(FEAS) / 技术思路(TECH)，各 1–5 分。
> 目的：先筛掉"看似好做但平庸"和"看似新颖但不落地"的方向，再提出经得起评委追问的精炼方案。

---

## 1. 八方向四维评分矩阵

| # | 方向 | BV | INN | FEAS | TECH | 综合 | 致命短板 |
|---|---|---|---|---|---|---|---|
| A | Listing 工厂 | 4.5 | 2.0 | 4.5 | 4.0 | 3.75 | 创新性太低，AI 上架工具已严重红海（Jasper/各类 Amazon AI 工具） |
| B | 爆款短片 | 4.0 | 2.5 | 3.0 | 3.0 | 3.10 | 视频生成异步且慢、易失败；AI 广告生成赛道也拥挤 |
| C | 多语客服 | 4.0 | 2.0 | 4.0 | 4.0 | 3.25 | 客服 Bot 毫无新意（Zendesk/Intercom 都已做） |
| D | 合规守门员 | 3.0 | 3.0 | 4.0 | 4.0 | 3.25 | "合规"太宽泛难聚焦；多被大工具打包 |
| N1 | 退件法医 | 4.5 | 4.5 | 3.0 | 3.0 | 3.60 | "AI 判定责任方"不可靠且有法律/采信风险 |
| N2 | 直播守门员 | 4.0 | 4.5 | 2.5 | 3.0 | 3.25 | "实时"接入直播流在工程上几乎不可为，易沦为模拟 |
| N3 | 报关大脑 | 4.5 | 4.0 | 3.0 | 3.5 | 3.60 | HS 编码若幻觉将成法律责任，须强 grounding |
| N4 | 一图懂装 | 3.0 | 3.0 | 3.0 | 3.0 | 3.00 | 只解决"误退"子集，价值与新颖都中庸 |

### 矩阵读出的三条规律
1. **A/B/C 高可行却低创新** → 评委一句"这跟现有工具有什么区别"就破功。
2. **N1/N2/N3 高价值高创新，但各有一处" feasibility/严谨性"硬伤**：
   - N1 的硬伤是"AI 替人裁定责任"（主观、不可采信）；
   - N2 的硬伤是"实时接入直播流"（工程不可为）；
   - N3 的硬伤是"HS 编码幻觉"（法律风险）。
3. **胜负手不是挑最炫的，而是挑"高价值+高创新+把硬伤拆掉"的那个。**

## 2. 幸存者分析
- 直接淘汰：A、B、C（创新不足）、D、N4（聚焦度/价值中庸）。
- 进入精炼池：N1、N2、N3。
- 精炼原则：**保留其高 BV+高 INN，移除 feasibility 硬伤**——
  - N1 → 把"判定责任"改为"构建客观证据卷宗"（不裁决，只取证）；
  - N2 → 把"实时直播"降级为"准实时片段巡检"（可演示、可落地）；
  - N3 → 把"直接给编码"改为"AI 建议+官方税则库 RAG 校验+人工确认"。

## 3. 精炼旗舰方向：ReturnGuard · 跨境退货举证官（N1 去风险版）

### 业务价值（4.5/5）
跨境退货率 20–30%，纠纷单平台多判买家赢，卖家净亏货款+运费。**核心不是"AI 判谁对"，而是"卖家从没能力拿出客观证据"**。本方案把每次退货变成一份可被平台仲裁采信的视觉证据卷宗，直接挽回赔款。ROI 极硬：少输一场纠纷即回本。

### 创新性（4.5/5）
"退货视觉取证"在跨境赛道几乎空白。差异化在于**用多模态向量做"同款一致性"客观度量**，而非靠人工肉眼争论。竞品（如 Returns 管理 SaaS）做的是流程，不做视觉取证。

### 可行性（4/5，去风险后）
- 全链路**批处理、非实时**：退件照片是卖家/仓库事后上传，天然异步，无需直播级延迟。
- 关键能力（图向量比对）正是我们即将用脚本验证的 `tongyi-embedding-vision-plus`，跑通即证明核心可行。
- 移除"AI 判定责任"这一不可采信环节 → 法律风险归零。

### 技术思路（4.5/5）
```
退回实物图 + 本店 original 主图/详情图
  ├─ 同款一致性     → tongyi-embedding-vision-plus 图向量 → 余弦相似度（是否同一 SKU/被调包）
  ├─ 瑕疵/状态识别   → qwen3-vl-plus 标注破损位置、污渍、缺件（客观描述，不下结论）
  ├─ 与描述一致性    → qwen3-max 比对"退回件实际状态" vs "本店 listing 承诺状态"
  ├─ 证据卷宗生成    → qwen3-max 输出结构化《举证报告》+ 关键帧红框标注
  ├─ 母语语音陈述    → qwen3-tts 生成 60 秒语音，直提交平台仲裁
  └─ 案件优先级      → qwen3-vl-rerank 把高金额/高胜算案件排前
```
**关键修正**：所有输出都是"客观证据 + 相似度分数"，最终由平台/人裁决；AI 只做取证与信息组织。这使得方案既新颖又经得起"这结论靠谱吗"的追问。

### 风险缓解清单
- 相似度阈值校准：用卖家历史"真同款/真调包"样本标定阈值，写入方案"模型校准"小节。
- 不出具责任结论，只出具证据强度评分（如"同款相似度 0.92 / 瑕疵类型：边角磕碰"），免责且更可信。
- 多图融合：主图+详情图+包装图多张向量取平均，抗单图角度偏差。

## 4. 备选精炼方向（同池，按场景二选一）

### 4a. LiveGuard · 准实时直播巡检（N2 去风险版）
- 把"实时直播流"改为"主播/导播上传的直播片段（30–60s）做准实时巡检"，保留 ASR 违禁词 + VL 画面敏感物双通道 + TTS 耳返提醒。
- 演示可现场录一段含违禁词的视频 → 系统报警，冲击力强；工程上完全可落地。
- 适合"演示炸场优先"的打法。

### 4b. CustomsGuard · 报关 AI 助手（N3 去风险版）
- 图（`qwen3-vl-plus`）识物 + `deepseek-r1` 推理候选 HS 编码 + **官方税则库 RAG 校验** + 受限清单命中 + 人工确认位。
- 价值硬（扣关/罚款/退运），但需准备一份 HS 税则知识库做 grounding，工作量略大。

## 5. 与 API 验证的衔接
我们已写好 `verify_api.py`，优先验证 **图向量比对（ReturnGuard 核心）** 与 **TTS→ASR 闭环（LiveGuard 核心）**：
- 若图向量比对 PASS → ReturnGuard 技术地基成立，主推它；
- 若图向量比对不稳 → 回退到 CustomsGuard（不依赖向量质量）或 LiveGuard。
即：**验证结果直接决定最终主推方向**，而非凭想象。

- **一句话定位**：用多模态 AI 把"说不清的退货纠纷"变成"平台不得不认的客观证据"。
