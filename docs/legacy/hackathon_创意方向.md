## 0. 这份 API 真正"能打"的能力（决定方向的前提）

| 能力域 | 关键模型（节选） | 对跨境的价值 |
|---|---|---|
| 文本对话 | `qwen3-max`（旗舰）、`qwen3.6-flash`（快）、`qwen-long`（长文）、`qwq-plus`/`deepseek-r1`（推理）、`qwen3-coder`（编码） | 多语言文案、政策推理、自动化脚本 |
| 第三方文本 | `deepseek-r1`、`kimi-k2-thinking`、`glm-5`、`MiniMax-M2.5` | 意图理解、长文分析、多语生成 |
| 视觉/多模态 | `qwen3-vl-plus`、`qwen-vl-ocr`、`qwen3.5-omni-plus`（全模态） | 看图写文案、竞品图识别、OCR 提取 |
| 图片生成/编辑 | `wan2.7-image-pro`、`wan2.7-image`、`qwen-image-edit-plus` | 主图/场景图/换背景/风格迁移 |
| 视频生成 | `wan2.7-t2v`、`wan2.7-i2v`、`wan2.7-r2v`、`happyhorse-1.0-*`、`wan2.7-videoedit`（共 18 个） | 商品短片、广告素材自动化 |
| 语音 | `qwen3-tts-instruct-flash`（Chelsie/Ethan/Serena）、`qwen3-asr-flash`、`paraformer-v2` | 多语配音、买家语音转写 |
| 向量 | `text-embedding-v4`、`tongyi-embedding-vision-plus`（图向量）、`qwen3-vl-embedding` | 语义去重、以图搜图、品牌一致性 |
| 排序 | `qwen3-rerank`、`gte-rerank-v2`、`qwen3-vl-rerank`（多模态） | 关键词/素材相关性重排 |

**关键约束（初赛方案里要体现可行性意识）：**
- 视频生成、旧版图片模型（`wan2.5/2.2`）为**异步调用**，需 `X-DashScope-Async: enable` + 轮询 `/v1/tasks/{task_id}`。
- `qwq` 系列**仅支持流式**（`stream:true`）。
- 多模态向量/排序有专属 JSON 格式（文档已给示例）。

> 结论：本 API 的差异化不在"又一个聊天机器人"，而在 **一套接口打通 文/图/视频/语音/向量/排序**。最优方向应让多个模态**串联成流水线**，这才是评委眼里的"AI 落地跨境场景"。

## 方向 A（★推荐）：「Listing 工厂」跨境商品一键多平台多语言上架

### 场景与痛点
一个中国跨境卖家有一款新品（如"便携榨汁杯"），想同时铺 **Amazon US / Amazon JP / TikTok Shop UK / Shopee MY / Temu**。
每个平台每语种需要：标题、5 点描述、详情、搜索关键词、5–8 张图（白底主图+生活场景图+A+）、可选 15 秒广告短片+配音。
- 现状：找服务商做一套约 **$500–2000 / 品 / 市场**，周期 **1–2 周**，多语质量参差、易违规。
- 卖家核心诉求：**快、便宜、合规、本地化地道**。

### 目标用户
SKU 多、需多平台多语上架的中小跨境卖家 / 品牌出海团队。

### 产品功能
1. **单图入，全栈出**：上传 1 张供应商图/实物图，勾选目标平台+语种，一键产出"上架物料包"（图文+视频+配音）。
2. **本地化文案引擎**：按各平台风格规则生成标题/要点/详情/关键词（`qwen3-max` + `qwen-long` 长上下文吃平台规范）。
3. **场景图工厂**：自动生成符合当地审美的生活场景图（美式厨房 / 日式极简 / 东南亚家庭），支持白底抠图与风格迁移（`wan2.7-image` + `qwen-image-edit-plus`）。
4. **短视频+配音**：主图转 15 秒卖点短片（`wan2.7-i2v`）+ 本地音色配音（`qwen3-tts`）。
5. **合规与去重**：OCR 提取竞品文案参考（`qwen-vl-ocr`）；用 `qwen3-rerank` 给关键词按搜索意图重排；用 `text-embedding-v4` 做品牌语气一致性/侵权近似检测。

### 技术路线（直接映射 API）
```
供应商图
  ├─ OCR 竞品参考      → qwen-vl-ocr
  ├─ 场景图生成        → wan2.7-image / qwen-image-edit-plus
  ├─ 多语文案          → qwen3-max（每语种 system prompt 含平台规范）
  ├─ 关键词重排        → qwen3-rerank（query=搜索意图, docs=候选词）
  ├─ 短片生成(异步)    → wan2.7-i2v + 轮询 /v1/tasks/{id}
  ├─ 本地配音          → qwen3-tts（voice 按语种选 Chelsie/Ethan/Serena）
  └─ 品牌一致性校验    → text-embedding-v4 向量比对
                 ↓
      按平台打包导出（CSV/A+ HTML/视频）
```

### AI 如何落地跨境
- **本地化不是翻译，是"重写"**：用 LLM 把卖点按目标国文化/度量/合规重写（如英制单位、CE/FCC 表述）。
- **视觉本地化**：图像生成按地区审美生成场景，避免"中式直邮感"。
- **合规前置**：生成即校验禁词/知识产权近似，降低封号风险。

### 差异化亮点
一套 API 串联 6 个模态成"生产线"，而非单点工具；输出可直接上架，闭环明确。

### 初赛可行性
PPT 讲清流水线 + 各节点模型选型即可；可展示 1 个真实样品（1 图→多平台物料包）截图。

## 方向 B：「爆款短片」TikTok Shop 跨境短视频广告自动生产线

### 场景与痛点
TikTok Shop / Reels 卖家需 **每周 20+ 条** 本地化新素材（hook+画面+字幕+配音），外包约 **$200/条**，创意易枯竭、合规词易踩雷。

### 产品功能
1. **爆款结构解析**：上传 3–5 条已验证爆款视频，`qwen3-vl-plus` 分析镜头结构/钩子类型，沉淀"爆款模板库"。
2. **脚本生成**：`qwen3-max` 按模板+本地俚语写 hook 与口播稿（美/英/东南亚口音区分）。
3. **素材生产**：图生视频 `wan2.7-i2v` / 文生视频 `wan2.7-t2v` / 参考图视频 `wan2.7-r2v` 批量出片；`wan2.7-videoedit` 做剪辑。
4. **配音+字幕**：`qwen3-tts` 本地音色配音；`qwen3-asr` 从配音反推时间轴字幕。
5. **合规扫描**：`qwen-vl-ocr` 抽帧识别画面违禁词/Logo，`qwen3-max` 审口播敏感词。

### 技术路线
VL 解析 → LLM 写脚本 → 视频生成(异步轮询) → TTS 配音 → ASR 字幕 → OCR 合规扫描 → 成片。

### 亮点
把"玄学创意"变成"模板+批量生产"，用视频生成模型规模优势碾压人工外包。

## 方向 C：「听得懂的多语客服」跨境卖家语音/图片客服智能体

### 场景与痛点
买家通过 WhatsApp/Instagram DM 发**语音条+商品破损照片**，语种混杂（英/西/阿/日）。
卖家时差大、回复慢 → 丢单、差评、退款率上升。

### 产品功能
1. **语音入口**：`qwen3-asr` / `paraformer-v2` 转写买家语音（多语）。
2. **意图+多模态理解**：`deepseek-r1` 推理买家意图（退换/尺码/物流）；`qwen3-vl-plus` 看买家发来的破损图判断责任。
3. **母语回复**：`qwen3-max` 用买家语言生成专业回复；`qwen3-tts` 回语音条。
4. **知识库检索**：用 `text-embedding-v4` + `qwen3-rerank` 从店铺 FAQ/物流政策中检索精准答案。
5. **风险提示**：识别"投诉/差评倾向"并升级人工。

### 技术路线
ASR → (VL 看图 + R1 推理意图) → 向量检索 FAQ → LLM 母语回复 → TTS 回语音。

### 亮点
直击"语音+图片"真实客服场景，多模态+推理组合，体验差异明显。

## 方向 D：「合规守门员」跨境 Listing & 广告内容风险审查

### 场景与痛点
Amazon 等平台**封号多因**：侵权词、误导性宣称、商标近似、图片含竞品 Logo。
人工审 1000 条 Listing 成本高、漏检多。

### 产品功能
1. **图文双审**：`qwen-vl-ocr` 抽图文案+识图 Logo；`qwen3-max` 判违禁宣称（"最/第一/医用"等）。
2. **商标/侵权近似**：`text-embedding-v4` + `tongyi-embedding-vision-plus`（图向量）比对品牌库，找近似。
3. **多模态排序聚焦**：`qwen3-vl-rerank` 把"最危险"的图文对排到前面优先人工复核。
4. **一键改写**：命中风险项自动 `qwen3-max` 给出合规替代文案。

### 亮点
把"事后封号"变"事前拦截"，ROI 清晰，企业愿付费。
