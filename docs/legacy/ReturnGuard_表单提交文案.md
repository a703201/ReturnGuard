## ③ 方案概述（实测约 680 字，≤1000）

**一句话定位**：ReturnGuard 把每一笔退货纠纷沉淀为市场洞察信号，帮跨境卖家"少赔一单、看清一类"——它既是单案举证工具，更是售后数据驱动的选品避坑与品控洞察引擎。参赛赛道即为 **AI 市场洞察**：用多模态取证沉淀海量真实退货"负向信号"，最终转化为可执行的选品与竞争策略，直接对应官方定义。

**解决的问题 / 痛点**：
1. 跨境退货率普遍 20%–30%，平台多判买家赢；卖家败诉主因不是理亏，而是拿不出客观证据（是否同款 / 是否被调包 / 是否货不对板）。
2. 多语种平台下，卖家不会写有说服力的本地化举证陈述。
3. 长期只"单案救火"，缺乏群体层洞察，看不清退货的结构性来源（哪些 SKU / 品类 / 供应商是重灾区）。

**核心功能（5 项）**：
1. 同款一致性比对（图向量）：退回图 vs 本店主图输出余弦相似度，判断是否调包；
2. 瑕疵视觉识别：自动标注破损 / 缺件 / 污渍 / 使用痕迹（**只描述、不裁决**）；
3. listing 承诺一致性核验：退回件实际状态 vs 本店承诺，检测货不对板；
4. 一键证据卷宗 + 母语语音：结构化《举证报告》+ 关键帧标注 + TTS 语音，直提交平台仲裁；
5. **退货群体洞察（主交付 · 赛道核心）**：聚合历史案件聚类缺陷根因、定位高纠纷 SKU / 供应商，输出《选品 / 品控洞察报告》与整改建议（换供应商、加固包装、改写 listing 承诺等），反哺选品决策。

**方案亮点**：用图向量把"像不像"变成可量化分数；AI 只取证不裁决，规避法律风险；多语母语举证；**把售后成本中心变成市场洞察数据源**（已成交的真实退货信号比公开评论更可信）；一套 API 串联 7 项能力。

**预期效果**：单案举证 2–3 小时 → 3–5 分钟；胜诉率目标 +20–30 个百分点，直接挽回赔款；洞察层从源头降低退货占比，选品从"凭感觉"变"凭数据"。

## ④ 技术方案（实测约 480 字，≤500）

**模型（均经阿里云百炼 Model Router 调用）**：`tongyi-embedding-vision-plus`（图向量）、`qwen3-vl-plus`（瑕疵识别）、`qwen-vl-ocr`（listing 承诺提取）、`qwen3-max`（卷宗 / 陈述 / 洞察聚类）、`qwen3-rerank`（排序）、`qwen3-tts`（母语语音）、`deepseek-r1`（根因推理）。

**工作流（双阶段）**：
- A 个案举证 = 上传 → 三路并行取证（图向量 + VL + OCR）→ 一致性核验 → 卷宗 + 语音 → 排序 → 案件沉淀；
- B 群体洞察（**赛道核心**）= 异步聚合 → 聚类归因 → 选品 / 品控建议 → 反哺选品与 listing。

**数据处理**：图存对象存储生成公开 URL 供模型拉取；相似度本地余弦计算，阈值用历史样本标定；每案产出 {SKU, 相似度, 缺陷, 金额, 结果} 存案例库供洞察层；图片可选不留存、结果可审计。

**组件**：前端（上传 / 卷宗 / 洞察看板）、后端 FastAPI、对象存储 + 轻量 DB、容器化；`verify_api.py` 验证图向量比对与 TTS→ASR 闭环。
